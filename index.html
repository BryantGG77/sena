Mi proyecto SENA subiendo mi primer trabajo a GitHub

Este es un proyecto de prueba para aprender a subir archivos a GitHub desde el SENA.

Lista de tareas

  • Crear un repositorio en GitHub
  • Clonar el repositorio en mi máquina local
  • Agregar archivos al repositorio
  • Hacer commit de los cambios
  • Subir los cambios a GitHub
